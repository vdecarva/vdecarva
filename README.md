### 🛠️ What I spend my days poking at

- ☁️ **OpenStack** — Nova, Neutron, Cinder, Glance, Octavia *(built one from scratch, still have the scars)*
- 🧱 **PaaS** — Jelastic / Virtuozzo, containers that won't start and the logs that won't say why
- 🐬 **Databases** — Percona MySQL on Kubernetes, operators, GTID archaeology
- 🕸️ **Linux networking** — OVS, VXLAN, BGP/FRR, iptables/nftables, `tcpdump` on the wrong interface first
- 💾 **Storage** — Ceph RBD, volumes stuck in `deleting`, the eternal question *"where did that disk go?"*
- ⚙️ **Config management** — Puppet, Salt
- 🐍 **Tooling** — Python automation so nobody has to do the same rescue twice

> My favourite kind of bug lives at the intersection of the application, the hypervisor, the network fabric and the database — all at once, ideally on a Friday.
